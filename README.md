# ai4pakistan website

Public website prototype for **ai4pakistan**, a MirasAI initiative focused on voice AI, datasets, benchmarks and developer tooling for Pakistani languages.

## Current build

- Responsive static homepage
- Sunno, Awaz, Pehchan, PakVoices, Kasauti and Baat product sections
- Dataset catalogue preview with non-fabricated placeholder states
- Kasauti benchmark preview
- Developer/API code examples
- Urdu/Punjabi/Sindhi/Pashto/Saraiki language demo tabs
- Solutions and partnership sections
- GitHub Pages deployment via GitHub Actions

## Local preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Deployment

This repository deploys automatically to GitHub Pages on every push to `main`.

Expected URL:

https://avais392.github.io/ai4pakistan-website/
